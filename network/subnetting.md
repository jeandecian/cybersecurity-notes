# Subnetting

## Subnet Mask & CIDR Notation

|  x  | x.0.0.0 | 255.x.0.0 | 255.255.x.0 | 255.255.255.x |
| :-: | :-----: | :-------: | :---------: | :-----------: |
| 128 |    /1   |     /9    |     /17     |      /25      |
| 192 |    /2   |    /10    |     /18     |      /26      |
| 224 |    /3   |    /11    |     /19     |      /27      |
| 240 |    /4   |    /12    |     /20     |      /28      |
| 248 |    /5   |    /13    |     /21     |      /29      |
| 252 |    /6   |    /14    |     /22     |      /30      |
| 254 |    /7   |    /15    |     /23     |      /31      |
| 255 |    /8   |    /16    |     /24     |      /32      |

{% hint style="info" %}
A subnet mask of `255.224.0.0` is `11111111.11100000.00000000.00000000` in binary, or `11` ones, hence `/11`.
{% endhint %}
